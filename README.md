# سکوت پرهیاهو — نسخه ۲۲ غزل

این بسته یک پروژه مستقل و آماده برای GitHub Pages است.

## ساختار
- `index.html` — صفحه اصلی
- `style.css` — طراحی، ریسپانسیو و افکت‌ها
- `script.js` — تعاملات، فهرست، خوانش، کپی، اشتراک‌گذاری، جست‌وجو و صدا
- `poems.js` — متن کامل هر ۲۲ غزل
- `assets/hero.jpg` — تصویر هدر
- `assets/audio/` — موسیقی موجود در نسخه قبلی

## انتشار در GitHub Pages
همه فایل‌ها را در ریشه Repository قرار بده؛ نام `index.html` را تغییر نده.
در Settings → Pages، Source را روی `Deploy from a branch`، Branch را روی `main` و Folder را روی `/ (root)` بگذار.

نکته: پخش خودکار صدای بدون تعامل ممکن است توسط مرورگر مسدود شود؛ کد سایت در نخستین تعامل کاربر دوباره پخش را امتحان می‌کند.
