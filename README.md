# سکوت پرهیاهو — NIGHTFOLIO FINAL

نسخه‌ی نهایی مستقل برای GitHub Pages.

فقط کافی است تمام محتویات این پوشه را در ریشه‌ی یک repository جدید قرار دهید و GitHub Pages را روی `main / (root)` فعال کنید.

ساختار:
- `index.html`
- `style.css`
- `script.js`
- `poems.js`
- `assets/` شامل تصاویر طراحی‌شده

این نسخه وابستگی اجباری به Three.js یا کتابخانه‌ی خارجی ندارد و برای لپ‌تاپ و موبایل طراحی شده است.
