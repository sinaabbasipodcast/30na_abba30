# سکوت پرهیاهو — سیناعباسی

نسخه‌ی ایستا و آماده‌ی GitHub Pages.

## ساختار
- `index.html` — صفحه‌ی اصلی
- `style.css` — هویت بصری، ریسپانسیو، عمق سه‌بعدی و انیمیشن‌ها
- `script.js` — فهرست، مودال کتاب، جست‌وجو، شاه‌بیت‌ها، هاله‌ی موس و پخش‌کننده
- `poems.js` — ۲۲ غزل/نوشته‌ی واردشده برای نسخه‌ی نهایی
- `assets/hero.png` — تصویر هدر
- `assets/audio/` — قطعه‌های بی‌کلام تولیدشده برای این سایت

## GitHub Pages
همه‌ی فایل‌ها را با همین ساختار در ریشه‌ی Repository قرار دهید و GitHub Pages را روی Branch `main` و Folder `/ (root)` فعال کنید.

### نکته‌ی پخش خودکار
مرورگرها ممکن است پخش صدادار خودکار را مسدود کنند. سایت در ورود تلاش می‌کند پخش را شروع کند؛ اگر مرورگر اجازه ندهد، با اولین تعامل کاربر موسیقی شروع می‌شود.

## لینک مستقل شعرها
هر شعر با شناسه‌ای مثل `#poem-01` باز می‌شود و دکمه‌ی اشتراک‌گذاری همان لینک را می‌سازد.
